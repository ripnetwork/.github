**ripnetwork** is an independent software organization focused on developing networking tools, infrastructure, and utilities designed for performance, reliability, and control.

## Projects

Ripnetwork develops and maintains open-source software across networking, infrastructure, and systems engineering.

Explore our repositories to discover current projects, experiments, and tools.

## Mentality

- **Open source.**: Build software that can be inspected, modified, and improved.
- **Performance.**: Reliable tools without tanking memory.
- **Control.**: Give developers the tools to understand and manage their infrastructure.
- **Reliability.**: Build with resilience, transparency, and maintainability in mind.
